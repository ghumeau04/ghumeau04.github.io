# Portfolio de Gauthier Humeau

Site statique (HTML, CSS, JavaScript), sans dépendance externe, prévu pour GitHub Pages.

- Français par défaut, anglais via le bouton FR/EN.
- Lien direct vers la version anglaise : https://ghumeau04.github.io/?lang=en

## Avant la mise en ligne
Déposer les deux CV dans le dossier `cv/`, avec exactement ces noms :
- `cv/CV_Gauthier_Humeau_FR.pdf`
- `cv/CV_Gauthier_Humeau_EN.pdf`

## Structure
- `index.html` : contenu (chaque texte existe en `data-l="fr"` et `data-l="en"`)
- `style.css` : mise en forme
- `main.js` : bouton de langue et agrandissement des images
- `img/` : captures des projets
- `fonts/` : police Archivo (licence OFL)
